# 办公用品申领管理平台

多组织、四级审批、全流程留痕的办公用品申领管理系统。纯前端单页应用，零构建、零服务器。

## 核心功能

- 物品清单申领：勾选物品+数量，实时金额合计，用途必填
- 按金额分级审批：小额（默认≤200元）仅部门初审；大额走初审+分公司复审；阈值可配置
- 四级审批闭环：提交 → 部门初审 → 分公司复审 → 发放 → 员工确认领取；任一环节可驳回（必填理由），驳回可修改重提（版本留痕）
- 进度全程可查：状态时间线记录每步操作人与时间
- 站内待办提醒：各角色登录见红点徽章与待办列表
- 多维统计报表：按人/部门/公司/物品四维度，支持月份筛选与 CSV 导出
- 多组织数据隔离：分公司管理员仅见本单位，集团超管见全局
- 超管管理台：组织架构（公司-部门两级）、用户与角色分配、物品清单、审批阈值配置
- 移动端/PC 双端自适应

## 技术说明

- 单 HTML 文件（原生 JS，hash 路由，零依赖）
- 数据层为 DB 对象统一接口，当前为 localStorage 演示模式；接入 Supabase/Firebase/LeanCloud 只需替换 DB 内部实现，接口签名不变
- 部署于 GitHub Pages（Actions 自动部署）

## Non-goals

不做财务/ERP对接、采购管理、库存台账联动、额度管控、外部消息推送。

## 已知边界（演示模式）

数据存储于浏览器 localStorage，同一浏览器内多角色流程完整可用；跨设备数据共享需接入云数据库。密码为演示明文，正式接入需改为哈希存储。

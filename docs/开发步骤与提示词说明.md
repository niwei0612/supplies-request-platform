## 开发步骤与提示词

### 步骤 1：数据层与登录系统

**提示词：** 开发办公用品申领管理平台的数据层与登录系统：localStorage 演示模式（接口可替换云数据库）；预置 2 家分公司、4 个部门、7 个演示账号（覆盖员工/部门负责人/分公司管理员/集团超管四角色）、10 种办公用品、7 张不同状态的演示申领单；登录页账号密码校验，按角色进入对应工作台。

**操作结果：** 登录页含演示账号一键填充；四种角色登录后按角色渲染导航与工作台；会话保持（刷新免重登）。
**截图：** 01-登录页.png

### 步骤 2：员工端申领

**提示词：** 开发员工端功能：新建申领（物品清单勾选+数量+实时金额合计+用途必填+按金额自动判定审批级别）；我的申领列表（状态筛选+进度查看）；提交后按阈值（默认 200 元）自动分流小额/大额审批链。

**操作结果：** 员工工作台含状态概览卡片与进行中列表；新建申领实时计算金额（验证：A4 纸×8+文件夹×25=246 元>200，判定大额）；提交成功 toast 提示分流去向。
**截图：** 02-员工工作台.png、03-新建申领-物品勾选与实时金额.png、04-提交成功-大额单待初审.png

### 步骤 3：四级审批链闭环

**提示词：** 开发四级审批链闭环：部门负责人初审（通过按金额分流：小额直入待发放、大额转待复审；驳回必填理由）；分公司管理员复审与发放登记；员工确认领取；驳回单修改重提（版本号+1，保留历史轨迹）；各角色待办红点徽章。

**操作结果：**
- 大额单初审通过 → 正确流转"待复审"（截图 05/06）
- 小额单初审通过 → 正确直入"待发放"
- 驳回：空理由被拦截，填理由后单据转"已驳回"
- 复审通过 → 待发放 → 标记发放 → 待领取 → 员工确认 → 已完成，完整闭环日志：提交→初审通过→复审通过→已发放→确认领取（截图 08）
- 驳回重提：查看理由→修改数量→v1→v2 重新进入待初审（截图 09）
- 待办红点：负责人登录显示 3，分公司管理员显示待复审 2+待发放 2（截图 05/07）

**截图：** 05-负责人初审工作台-待办红点.png、06-初审后流转与驳回.png、07-分公司管理员-复审与发放工作台.png、08-申领详情-物品明细与流转时间线.png、09-驳回重提-查看理由并修改.png
